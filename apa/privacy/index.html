Privacy Policy

Last updated November 26, 2026

Page and citation data

When you use APA Website Citation Generator on a selected page, it uses the page URL and, when you choose Read page details, reads available citation metadata. This can include personal or organization names credited as authors, publication dates, page titles, and website names.

The citation editor uses the fields you review or enter manually, including author names and the source URL, to format one APA 7 reference. Changing the URL in the editor only changes the citation data.

Local storage and clipboard

The extension processes citation data on your device. Chrome session storage holds the selected source and one draft for the current browser session. You can replace the draft by choosing Start over or end the browser session to clear that session storage.

Copy reference writes the reference as plain text to the clipboard managed by your browser and device. You control where you paste it. The extension also saves its language preference locally in Chrome for future sessions.

Welcome guide and website requests

On first installation, Chrome opens the hosted Welcome guide with the extension ID and, when available, whether its icon is pinned. The guide exchanges pin state and language settings with the paired extension. The guide stores its language choice in your browser.

When your browser loads the guide or this policy, the hosting provider receives standard web requests, including the requested address and IP address. A guide request may include the extension ID, pin state, or language. Site storage settings in your browser let you clear the guide’s saved language.

Limited Use

We handle information received through Chrome APIs in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements. Citation data is used only to create and copy the reference you request and stays on your device through editing and copying.

Contact

For questions about this policy, use the Support section of the APA Website Citation Generator listing in the Chrome Web Store when available.
