Privacy Policy

Last updated November 26, 2026

PDF data

Remove Blank Pages from PDF reads the name and contents of the PDF you choose from your device. The extension renders page previews in Chrome, keeps track of which pages you mark for removal, and uses those choices to build and preview a separate copy. Your original file stays on your device.

Local storage and downloads

The PDF, previews, page choices, and generated copy are processed locally in the workspace. Choosing another PDF or closing the workspace clears its working data. Download new copy saves the generated PDF through Chrome. You control any later sharing of the downloaded file and can delete it from the download location.

The extension stores its language preference locally in Chrome for future sessions. You can change it in the language menu.

Welcome guide and website requests

On first installation, Chrome opens the hosted Welcome guide with the extension ID and, when available, whether its icon is pinned. The guide exchanges pin state and language settings with the paired extension. The guide stores its language choice in your browser.

When your browser loads the guide or this policy, the hosting provider receives standard web requests, including the requested address and IP address. A guide request may include the extension ID, pin state, or language. Site storage settings in your browser let you clear the guide’s saved language.

Limited Use

We handle information received through Chrome APIs in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements. The file data is used only to preview and save the copy you request and stays on your device through processing and export.

Contact

For questions about this policy, use the Support section of the Remove Blank Pages from PDF listing in the Chrome Web Store when available.
