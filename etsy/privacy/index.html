Privacy Policy

Last updated November 26, 2026

Page and listing data

Etsy Scraper uses the URL of the Etsy page you select. When you choose to collect cards, it reads data already rendered in the public listing cards on that page. The captured table can contain listing titles, displayed prices, listing links, and tags visible in the available markup.

The workspace keeps the source page URL and title, capture time, and your review state with the current table so you can check the result before saving a CSV copy.

Local storage and downloads

The extension processes the captured data on your device. Chrome session storage holds the current source and capture while you review it. Clear table, closing the workspace, or ending the browser session removes the captured table from the extension. Chrome saves any CSV you choose to download on your device. You control any later sharing of that file and can delete it from the download location.

The extension stores its language preference locally in Chrome for future sessions. You can change it in the language menu.

Welcome guide and website requests

On first installation, Chrome opens the hosted Welcome guide with the extension ID and, when available, whether its icon is pinned. The guide exchanges pin state and language settings with the paired extension. The guide stores its language choice in your browser.

When your browser loads the guide or this policy, the hosting provider receives standard web requests, including the requested address and IP address. A guide request may include the extension ID, pin state, or language. Site storage settings in your browser let you clear the guide’s saved language.

Limited Use

We handle information received through Chrome APIs in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements. Listing data is used only to show and export the table you request and stays on your device through review and export.

Contact

For questions about this policy, use the Support section of the Etsy Scraper listing in the Chrome Web Store when available.
