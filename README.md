# Welcome Page для четырёх расширений

Статические страницы для Timeweb Cloud App Platform. Главная страница сайта ведёт к каждой инструкции.

| Путь | Расширение |
| --- | --- |
| `/meta/` | Meta Tag Analyzer |
| `/etsy/` | Etsy Scraper |
| `/apa/` | APA Website Citation Generator |
| `/pdf/` | Remove Blank Pages from PDF |

В мастере App Platform выберите ветку `main`, формат **HTML/CSS/JS** и корень репозитория. Главная страница — `index.html`. [Документация Timeweb Cloud](https://timeweb.cloud/docs/apps/deploying-frontend-apps/static-website)

Каждая страница открывается в режиме закрепления по умолчанию. Ссылки с `#pin` и `#usage` сразу показывают нужную инструкцию. Обе инструкции доступны напрямую.

При первой установке поддерживаемые сборки передают ID расширения и, если Chrome его вернул, начальное состояние закрепления. Видимая страница обновляет режим по ответу расширения. Ручной выбор сохраняется, пока действует выбранный фрагмент URL.
